## Portfolio decisions

- The root site uses the existing Brain Burst Studio logo and palette from `brain_burst_studio_v2`.
- It presents all ten game projects, with Arrow Way featured and nine games in the filterable shelf.
- Game descriptions stay close to implemented or documented mechanics. The site does not claim that any game is currently available on Google Play.
- Final public names, store listings, screenshots, privacy pages, and release links should be reviewed per game before adding download buttons.
