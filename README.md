# Brain Burst Studio website

Static studio portfolio for the local Brain Burst Studio game projects. The root page is designed for GitHub Pages and needs no build step.

## Preview

Open `index.html` in a browser, or serve this directory with `python -m http.server 8000` and visit `http://localhost:8000`.

## Content and assets

The page uses the studio logo from `brain_burst_studio_v2` and game images from sibling projects in `C:\games`. Copies live in `assets/` so GitHub Pages can serve them. The game shelf describes local projects at different development stages and does not imply public release or store availability.

The pre-existing `brainburst/` microsite, `app-ads.txt`, and Google verification file remain separate from the root portfolio.

Contact address: `support@brainburst.studio` (sourced from the Drop Number 2048 project README).
